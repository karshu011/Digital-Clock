# 🕒 Digital Clock

A simple and attractive Digital Clock application developed using HTML, CSS, and JavaScript. This application displays the current time and updates automatically every second.

## 🚀 Features

- 🕒 Display current time
- 📅 Display current date
- ⏰ Automatic time updates
- 🔄 Real-time clock functionality
- 🌞 12-hour time format with AM/PM
- 🌙 Clean and attractive design
- 📱 Responsive user interface
- ⚡ Easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

Digital-Clock/

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. View the current time and date.
5. The clock updates automatically every second.
